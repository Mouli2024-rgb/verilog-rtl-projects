# Booth's Algorithm Multiplier

## Overview

Implemented a sequential binary multiplier using Booth's multiplication
algorithm in Verilog HDL.

The design uses separate datapath and control-path logic to perform
binary multiplication.

## Design Components

- ALU
- Datapath
- Control Path
- Counter
- Shift Register
- PIPO Register
- D Flip-Flop

## Verification

A Verilog testbench was developed to verify the functionality of the
multiplier. Simulation waveforms were generated and analyzed using the
VCD output.

## Tools

- Verilog HDL
- Icarus Verilog
- GTKWave

## Concepts

- RTL Design
- Sequential Logic
- Datapath and Control
- Booth's Multiplication Algorithm
