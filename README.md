# Verilog RTL Projects

A collection of digital design and RTL projects implemented using Verilog HDL.

## Projects

### 1. Booth's Algorithm Multiplier
Designed and simulated a sequential binary multiplier using Booth's multiplication algorithm with separate datapath and control logic.

### 2. Datapath and Controller
Implemented a datapath-controller based digital system using Verilog RTL, including arithmetic, register, control, and comparison modules.

### 3. GCD Processor
Implemented a hardware-based Greatest Common Divisor (GCD) computation using Verilog.

### 4. Sequence Detector
Designed a sequential FSM-based sequence detector using Verilog.

### 5. Counters
Implemented various counter architectures:
- 6-bit Ripple Counter
- Ring Counter
- Up/Down Counter
- Basic Counter

### 6. Multiplexers
Implemented:
- 8-to-1 Multiplexer
- Multiplexer designs

### 7. Other Digital Designs
- Parity Generator
- XOR Generator
- LAMP-based design

## Tools & Technologies

- Verilog HDL
- RTL Design
- Digital Logic Design
- Finite State Machines (FSM)
- Sequential Circuits
- Datapath and Control
- Simulation and Verification

## Purpose

This repository documents my practice and implementation of RTL and digital design concepts as part of my preparation for VLSI and digital design roles.
